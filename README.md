# 帶薪打卡鐘

一個裝在 iPhone 主畫面的打卡小工具:

- 上班 / 下班打卡,下班倒數
- 尿尿、拉屎、抽菸計時,記次數和時長
- 一天的時間軸、摸魚統計、歷史紀錄
- 本月薪水 24 小時自動累積,不用打卡也會算

## 安裝

1. 用 iPhone 的 Safari 打開 https://cookfishbro.github.io/paid-punch-clock/
2. 點下方的分享按鈕,選「加入主畫面」
3. 之後從主畫面的「打卡鐘」打開,沒網路也能用

## 資料

所有紀錄只存在手機裡(瀏覽器的 localStorage),不會上傳到任何地方。
在「設定」可以備份全部資料、匯出 CSV,或匯入備份。
